# Maison Atelier

Boutique en ligne (frontend) de mobilier et décoration : catalogue filtrable, fiche produit, panier avec code promo, favoris, tunnel de commande en 3 étapes (paiement simulé).

**Stack** : React 18, Vite 5, Tailwind CSS 3, Framer Motion, React Router.

```bash
npm install
npm run dev
npm run build
```

Code promo de démonstration : `BIENVENUE10` (-10 %). Livraison offerte dès 150 000 FCFA.
